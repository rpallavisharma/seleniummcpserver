# Contributing

Contributions are welcome via pull requests from a fork.

1. Fork the repository and create a branch.
2. Make your change and run `python -m unittest discover -s tests`.
3. Open a pull request against `main`. All changes need review by a maintainer
   and passing checks before merging.
