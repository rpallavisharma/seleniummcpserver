# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/rpallavisharma/seleniummcpserver/security/advisories/new)
to report security problems. Expect an initial response within a few days.

## Scope

This server can drive a real browser and execute JavaScript on pages. Run it
only with MCP clients and prompts you trust, and avoid pointing it at
sensitive logged-in sessions.
